# 接下来两周做什么

目标：把现在这个"能跑的练习"变成"能写在简历上的小项目"。

## 第 1 周：能交互

现在 `App` 里的图形是写死的。这一周让它听人话。

1. 用 `Scanner` 读命令行输入，支持 `circle 2.5`、`rect 3 4`、`list`、`quit`
2. 用 `ArrayList<GeometricObject>` 存图形，替换掉固定长度的数组
3. 加 `sorted by area` 命令，按面积从大到小打印（提示：`Comparator`）

**验收**：能连续输入十次命令不崩，不认识的命令给提示而不是抛异常。

## 第 2 周：像个工程

1. 加第三个图形：`Triangle`（海伦公式），自己写，不许搜答案
2. 非法参数要抛出 `IllegalArgumentException`：半径 ≤ 0、三边构不成三角形
3. 在 `App` 里用 `try/catch` 接住异常，打印友好提示
4. 把 `README` 的"运行"一节更新成真实截图或真实输出

**验收**：README 里的命令，别人复制粘贴就能跑起来。

## 完成后

这个仓库就可以放进简历了。下一个项目不要再做练习——**去做一个别人真的会用一个小工具**，哪怕只是给班级做一个统计脚本。
